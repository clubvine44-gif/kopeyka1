# Копейка — Android Offline First

Нативная Android-версия финансового приложения.

## Архитектура

- Kotlin
- Jetpack Compose
- Room / SQLite — локальное хранилище и источник истины для работы приложения
- Supabase — облачная синхронизация и резервная копия
- WorkManager — фоновая синхронизация при появлении сети

## Принцип работы

Приложение должно полностью работать без интернета. Любая операция сначала записывается локально в Room и сразу отображается пользователю. При наличии сети операция синхронизируется с Supabase. Ошибка сети никогда не удаляет локальные данные.

## План

1. Перенести модель операций и финансовые расчёты.
2. Реализовать Room database.
3. Реализовать repository, работающий только через локальную БД для UI.
4. Добавить очередь pending sync.
5. Добавить Supabase sync worker.
6. Добавить первоначальный импорт существующей истории из Supabase.
7. Перенести интерфейс текущей «Копейки» в Compose.
8. Добавить тесты расчётов и offline/sync сценариев.

Существующий `main` не изменён этим этапом.
